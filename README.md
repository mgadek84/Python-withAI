# Budget Burn Counter (Streamlit)

Small Python app built with **Streamlit** — shows how fast a monthly budget burns in real time. Early experiment with AI-assisted development workflow.

## Run locally

```bash
pip install streamlit
streamlit run app.py
```

A later HTML/JS version lives in [TimeAndMoney_Counter](https://github.com/mgadek84/TimeAndMoney_Counter).
